My AI agent said “All tests passed!” So I asked for receipts.

The 30-second version

1

The AI writes code and runs it inside the sandbox, a locked room it can't escape.

2

Every run gets a signed receipt, stapled to the one before it, so none can be swapped or dropped.

3

You check the receipts. Change a single byte anywhere and the check refuses the lot.

The agentNVIDIA's Nemotron, an open AI model, rented by the token from Nebius Token Factory. It writes the code and decides when it's done.
The sandboxplimsolld, the sandbox daemon, running the code behind gVisor: the code can ask the operating system for things through a window, but can't reach over the counter.
The receiptFor every run: what went in, what came out, and where it ran, as fingerprints.
The notaryThe harness, a separate program that signs each receipt with a private key and staples it to the last one.
YouAnyone with the public key. Checking needs no account, no network and no trust in anyone named above.

Most of these aren't lies. Usually the agent's own tests really did pass; they just didn't test enough, which is exactly how real bugs ship. The receipts show what the agent actually ran, and the hidden tests show what it missed. A model that ran out of thinking room without answering counts as “no answer,” never as a false claim.

What this proves, and what it doesn't

Proves
  • Exactly what code was sent, what came back, and which sandbox and isolation tier the daemon reported.
  • The order of the runs, and that none was changed or dropped afterward.
  • That a claim and its evidence match, or don't, for anyone who checks.
Doesn't prove
  • That the code is correct. A grocery receipt proves what you bought, not that dinner was good.
  • That the hardware is honest: the isolation tier is the daemon's configuration and startup checks, not a hardware attestation.
  • Anything about runs that never went through plimsoll.

Run it yourself

Everything on this page comes from files beside it: bundle.jsonl (the receipts), harness.pub (the public key) and transcript.json (the conversation). From a clone of the repository (EXTERNAL · source repo ↗):

go run ./cmd/plimsoll-attest verify -pub docs/examples/nemotron-agent/harness.pub docs/examples/nemotron-agent/bundle.jsonl

The agent program is examples/nemotron-agent (EXTERNAL · source repo ↗): it starts plimsolld on Docker under gVisor, opens one session, and gives the model the task and the tool.
