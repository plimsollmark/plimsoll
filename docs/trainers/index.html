Learn the boundary, then trust the signal.

Eighteen compact trainers turn plimsoll's security model and product shape into decisions you can make. Change configurations, trace requests, design integrations, compare Docker's agent products, and test deployment gates without running untrusted code. The final four go deeper on the shared API broker, the caller's private API boundary, its shipped metadata-only advisor, and the capacity endpoint that makes backpressure recover early.
