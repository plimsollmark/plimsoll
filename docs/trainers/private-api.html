When an LLM asks which warehouses are short on stock, what process calls what process? Follow the actual messages from the model to MCP, through the Stockroom gateway and Go dataplane, into plimsoll, and back out to the private API.

Stockroom is a worked example, not a product. It is a fictional inventory platform: a Node gateway, a Go dataplane, and the same inventory.* API the grant examples in this repository use. Every process boundary and every wire message below is real; only the company is invented.

What each layer is actually responsible for

In this example, Stockroom owns two processes: the Node gateway and the Go dataplane. plimsoll owns its broker and provider; the caller owns the LLM/MCP host; the guest and WMS/ERP are outside the trusted Stockroom process boundary. “Private Stockroom API” is a shorthand for a route plus downstream service calls, not one mystery process.

FAIL THE ASSUMPTION

Which of these is the MCP tool?

MCP is the protocol used by the model’s host to call a registered server operation. The guest global is JavaScript that runs only after plimsoll starts the isolated guest. The REST route is a private gateway endpoint.

What each audience actually sees

Four windows into one call

The model, the MCP wire, the guest, and the private API have different contracts. Confusing these windows is how private APIs accidentally become public APIs.

So what does plimsoll bring?

A private API can be useful without becoming a sandbox capability free-for-all.

Stockroom keeps its domain API and its MCP product. plimsoll contributes the controlled middle: a place where agent-authored code can loop, filter, and compose private data while the origin, route policy, caller identity, token, network boundary, and audit semantics stay outside the guest.

01

Better than one-shot tools

inventory.items.counts(id) can sit inside a loop or condition. The model does not need one MCP round trip per item.

02

Safer than a raw SDK secret

The guest sees typed helpers. plimsoll holds the private origin and per-run credential, and allows only the registered routes.

03

Clearer than magic

The MCP description and stockroom://sandbox-api.d.ts explain the model-facing contract. The flight recorder explains the process-facing contract.
