shower: the draft controller against the accepted one

Scenario s1: hot-pipe volume 0.3 L, hot supply 60 C, cold-pressure drop at 40 s. Simplified plumbing, not calibrated to an installed shower. Both runs come from the built plimsoll/sandbox-sim image through the project API; the fingerprints below are the SHA-256 of each trajectory as recorded from that image.

The simulator is written in C, compiled to WebAssembly and shipped in that image: its source, EXTERNAL · source repo ↗. A controller is a separate program that reads the simulator's observations each tick and sets its input. This page runs two hand-written controllers against it: a draft that makes a plausible mistake and fails, and an accepted one that passes the environment's scoring program. The controllers, the scoring program and the other scenarios are not published. Every simulator in the image, EXTERNAL · source repo ↗.

Work in progress. These charts show two hand-written reference controllers. No AI-generated controller is plotted for this environment yet.
