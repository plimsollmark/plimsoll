satellite-clock: the draft controller against the accepted one

Scenario s1: eccentricity 0.02, oscillator offset 1e-10, ground measurements 600 s late. One day. Both runs come from the built plimsoll/sandbox-sim image through the project API; the fingerprints below are the SHA-256 of each trajectory as recorded from that image.

The plant (control engineering's word for the system being controlled) is C compiled to WebAssembly and shipped in that image: its source, EXTERNAL · source repo ↗. A controller is a separate program that reads the plant's observations each tick and sets its input. This page runs two hand-written controllers against it: a draft that makes a plausible mistake and fails, and an accepted one that passes the environment's scoring program. The controllers, the scoring program and the other scenarios are not published. Every model in the image, EXTERNAL · source repo ↗.

Work in progress. No model has been trained yet; these are the two hand-written reference controllers of the environment. The trained model's trace goes on these charts when it exists.
