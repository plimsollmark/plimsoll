The task

It must handle: "PT0S" -> 0, "PT1H30M" -> 5400, "P1DT2H" -> 93600, "P1W" -> 604800, "PT0.5S" -> 0.5, "P2DT3H4M5.25S" -> 183845.25, and it must raise ValueError for "", "P", "PT", "1H" and "P1H". Use 1 day = 86400 seconds and 1 week = 7 days; years and months are not supported and must raise ValueError. import re

def iso_duration_seconds(s):
    if not isinstance(s, str):
        raise ValueError("Input must be string")
    if s == "" or s == "P" or s == "PT":
        raise ValueError("Invalid duration")
    # Must start with P
    if not s.startswith('P'):
        raise ValueError("Duration must start with 'P'")
    # Split date and time parts
    if 'T' in s:
        date_part, time_part = s[1:].split('T', 1)
    else:
        date_part, time_part = s[1:], ''
    # Validate no unsupported units Y or M anywhere
    if re.search(r'[YM]', s):
        raise ValueError("Years and months not supported")
    total = 0.0
    # Parse date part: only D allowed
    if date_part:
        # Expect pattern like (\d+(\.\d+)?)D
        m = re.fullmatch(r'(\d+(?:\.\d+)?)D', date_part)
        if not m:
            raise ValueError("Invalid date part")
        days = float(m.group(1))
        total += days * 86400
    # Parse time part: H, M, S allowed, order not enforced but we parse sequentially
    if time_part:
        # Remove possible empty
        # Use regex to find all number+unit
        tokens = re.findall(r'(\d+(?:\.\d+)?)([HMS])', time_part)
        if not tokens:
            raise ValueError("Invalid time part")
        # Ensure we consumed whole string
        reconstructed = ''.join(num + unit for num, unit in tokens)
        if reconstructed != time_part:
            raise ValueError("Invalid time part format")
        for num, unit in tokens:
            val = float(num)
            if unit == 'H':
                total += val * 3600
            elif unit == 'M':
                total += val * 60
            elif unit == 'S':
                total += val
            else:
                raise ValueError("Unsupported unit")
    # Ensure at least one component contributed
    if total == 0 and s not in ("PT0S",):  # allow zero explicitly
        # but also PT0S should be allowed
        # check if any number present
        if not re.search(r'\d', s):
            raise ValueError("No duration specified")
    return total

        # However we need to allow M for minutes. So we check for Y only.
        if 'Y' in s:

                total += val * 86400

                total += val * 7 * 86400
            else:
                raise ValueError("Unsupported date unit")

Check it yourself

The bundle (bundle.jsonl) and the public key (harness.pub) sit beside this page. From a clone of the repository:

go run ./cmd/plimsoll-attest verify -pub harness.pub bundle.jsonl

That recomputes every record's digests from the stored request and response, checks every signature and the session's chain (call 2 closes it), and refuses the bundle if one byte of any run was changed or one call was dropped. The same program replays the session into a fresh sandbox:

go run ./cmd/plimsoll-attest replay -daemon http://127.0.0.1:8746 -pub harness.pub bundle.jsonl

How it was made

The program is examples/nemotron-agent in the plimsoll repository. It starts plimsolld on the docker provider under gVisor with the Python image, opens one session, and gives the model the task and the run_code tool. The model's code runs in the session; the result goes back to the model; the harness signs each exchange as the client makes it, and the session's close is signed with the count of calls. Nothing the page states about a run comes from the model: it comes from the daemon's answer, checked by the client, and signed.
